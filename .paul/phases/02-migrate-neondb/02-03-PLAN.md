<task type="auto">
  <name>Task 1: Rewrite services/dataService.ts</name>
  <files>services/dataService.ts</files>
  <action>
    Tulis ulang SELURUH `services/dataService.ts`. Hapus semua import dari `supabaseClient`.

    **Tambah helper function di bagian atas:**
    ```typescript
    async function apiFetch<T>(url: string, options?: RequestInit): Promise<T> {
      const res = await fetch(url, options);
      if (!res.ok) {
        let message: string;
        try {
          const body = await res.json();
          message = body.error || `HTTP ${res.status}`;
        } catch {
          message = `HTTP ${res.status}`;
        }
        throw new Error(message);
      }
      return res.json() as Promise<T>;
    }
    ```

    **Map setiap metode ke API call yang sesuai:**

    `getEmployees()` → `apiFetch<Employee[]>('/api/employees')`

    `saveEmployee(emp)` → `apiFetch('/api/employees', { method: 'POST', headers: {'Content-Type': 'application/json'}, body: JSON.stringify(emp) })`

    `deleteEmployee(id)` → `apiFetch('/api/employees?id=' + encodeURIComponent(id), { method: 'DELETE' })`
    Kemudian panggil `DataService.deleteUserByEmployeeId(id)` TIDAK perlu — endpoint DELETE /api/employees sudah menghapus app_user terkait. Hapus call ke `deleteUserByEmployeeId` dari `deleteEmployee`.

    `cleanupEmployees()` → tetap loop di frontend, panggil `checkEmployeeDependencies` + `deleteEmployee` per employee.

    `checkEmployeeDependencies(id)` → `apiFetch<{hasDependencies: boolean, details: {production: number, payments: number}}>('/api/employees?checkDeps=1&id=' + encodeURIComponent(id))`

    `getComponents()` → `apiFetch<Component[]>('/api/components')`

    `saveComponent(comp)` → POST ke `/api/components`

    `deleteComponent(id)` → DELETE `/api/components?id=...`

    `cleanupComponents()` → tetap loop di frontend.

    `checkComponentDependencies(id)` → `apiFetch('/api/components?checkDeps=1&id=' + encodeURIComponent(id))`

    `getProductionLogs()` → `apiFetch<ProductionLog[]>('/api/production-logs')`

    `saveProductionLog(log)` → POST ke `/api/production-logs`

    `deleteProductionLog(id)` → DELETE `/api/production-logs?id=...`

    `deleteAllProductionLogs()` → DELETE `/api/production-logs?all=1`

    `getPayments()` → `apiFetch<Payment[]>('/api/payments')`

    `savePayment(p)` → POST ke `/api/payments`

    `deletePayment(id)` → DELETE `/api/payments?id=...`

    `deleteAllPayments()` → DELETE `/api/payments?all=1`

    `login(username, password)` → POST ke `/api/auth` dengan body `{ username, password }`, return result atau null jika response adalah null

    `getUsers()` → `apiFetch<UserAccount[]>('/api/users')`

    `getUserByEmployeeId(empId)` → `apiFetch('/api/users?employeeId=' + encodeURIComponent(empId))`

    `saveUser(user)` → POST ke `/api/users`

    `updatePassword(username, oldPass, newPass)`:
    1. Call PUT `/api/users?action=password` dengan body `{ username, oldPass, newPass }`
    2. Setelah berhasil, update localStorage `borongan_current_user` (logika ini tetap di frontend)

    `deleteUserByEmployeeId(empId)` → DELETE `/api/users?employeeId=...`

    `resetData()` → tetap `localStorage.clear()` saja (tidak ada endpoint untuk ini)

    Tidak perlu `init()` — kosong atau hapus.

    Avoid: Jangan import apapun dari `./supabaseClient` — file ini akan dihapus.
    Avoid: Jangan tambahkan headers Authorization — API tidak perlu auth headers (konsisten dengan Supabase anon key model).
    Avoid: Jangan ubah return types — harus tetap compatible dengan semua komponen React yang memanggil DataService.
