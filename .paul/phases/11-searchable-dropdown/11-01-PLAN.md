<objective>
## Goal
Ganti tiga `<select>` di form input (Production + Payments) dengan komponen `SearchableSelect` yang memungkinkan user mengetik untuk memfilter pilihan secara realtime.

## Purpose
Dengan 27 karyawan dan 61 komponen, `<select>` biasa memaksa user scroll panjang. Admin yang sering input produksi harian sangat terbantu dengan kemampuan mengetik nama untuk langsung menemukan pilihan — terutama di mobile.

## Output
- `components/SearchableSelect.tsx` — komponen combobox reusable, zero dependency baru
- `components/Production.tsx` — dropdown Nama Karyawan + Komponen / Item diganti
- `components/Payments.tsx` — dropdown Karyawan diganti
</objective>

## AC-1: Filter realtime saat mengetik
```gherkin
Given form "Input Hasil Baru" atau "Transaksi Baru" terbuka
```

<task type="auto">
  <name>Task 1: Buat komponen SearchableSelect</name>
  <files>components/SearchableSelect.tsx</files>
  <action>
    Buat file baru `components/SearchableSelect.tsx` sebagai komponen combobox reusable.

    **Props interface:**
    ```tsx
    interface SearchableSelectProps {
      options: { value: string; label: string }[];
      value: string;
      onChange: (value: string) => void;
      placeholder?: string;
      required?: boolean;
    }
    ```

    **State yang dibutuhkan:**
    - `query: string` — teks di input field
    - `isOpen: boolean` — visibility dropdown
    - `containerRef: useRef` — untuk click-outside detection

    **Behavior yang harus diimplementasikan:**

    1. **Inisialisasi query dari value:** Saat komponen mount atau saat `value` prop berubah dari luar, set `query` ke label dari option yang memiliki `value` tersebut. Gunakan `useEffect` dengan `[value, options]` dependency.

    2. **Filter options:** `const filtered = options.filter(o => o.label.toLowerCase().includes(query.toLowerCase()))` — difilter realtime saat `query` berubah.

    3. **Saat input difokus:** Set `isOpen = true`, reset `query = ''` agar semua opsi tampil saat mulai mengetik.

    4. **Saat opsi diklik:** Panggil `onChange(option.value)`, set `query = option.label`, set `isOpen = false`.

    5. **Click outside:** `useEffect` yang add/remove `mousedown` event listener. Jika click target bukan di dalam `containerRef.current`, tutup dropdown dan kembalikan query ke label dari `value` saat ini.

    6. **Jika query dikosongkan dan blur:** Kembalikan query ke label yang saat ini terpilih (jangan biarkan input kosong jika ada value yang terpilih).

    **Styling (ikuti pola existing dari Production.tsx form):**
    - Container: `relative` (untuk positioning dropdown)
    - Input: `w-full px-4 py-3 md:py-2 border border-slate-200 dark:border-slate-700 rounded-xl dark:bg-dark-card focus:outline-none focus:ring-2 focus:ring-green-500 text-sm`
    - Dropdown list: `absolute z-50 w-full mt-1 bg-white dark:bg-dark-card border border-slate-200 dark:border-slate-700 rounded-xl shadow-lg max-h-60 overflow-y-auto`
    - Setiap item: `px-4 py-2.5 text-sm cursor-pointer hover:bg-slate-50 dark:hover:bg-slate-800 text-slate-700 dark:text-slate-300`
    - Item yang aktif/dipilih: tambah `bg-green-50 dark:bg-green-900/20 text-green-700 dark:text-green-400 font-medium`
    - Empty state (tidak ada hasil): `px-4 py-3 text-sm text-slate-400 italic`

    **Ikon:** Tampilkan `Search` icon dari lucide-react di sisi kiri input (absolute positioned), dan `ChevronDown` di sisi kanan.

    **JANGAN gunakan dependency baru** — hanya React hooks dan lucide-react yang sudah ada.
