<objective>
## Goal
Migrasi Tailwind CSS dari CDN (`<script src="https://cdn.tailwindcss.com">`) ke PostCSS build-time plugin, agar tidak ada CORS error di production dan tidak ada warning CDN di browser console.

## Purpose
Tailwind CDN menyebabkan dua masalah nyata di production:
1. Service Worker gagal cache `cdn.tailwindcss.com` (CORS block) → `sw.js` throw `TypeError: Failed to fetch`
2. Browser console menampilkan warning: "cdn.tailwindcss.com should not be used in production"

Dengan migrasi ke PostCSS, Tailwind di-bundle saat `npm run build` — tidak ada request CDN, tidak ada CORS, dan ukuran CSS lebih kecil (hanya utilities yang dipakai).

## Output
- `tailwind.config.js` — konfigurasi Tailwind v3 dengan custom theme dari index.html
- `postcss.config.js` — konfigurasi PostCSS (tailwindcss + autoprefixer)
- `index.css` — entry CSS dengan @tailwind directives + custom styles dari index.html
- `index.tsx` — ditambahkan `import './index.css'`
- `index.html` — dihapus CDN script + inline tailwind.config block
</objective>

<task type="auto">
  <name>Task 1: Install Tailwind v3 + buat tailwind.config.js + postcss.config.js</name>
  <files>package.json, tailwind.config.js, postcss.config.js</files>
  <action>
    1. Install dependencies:
       ```
       npm install -D tailwindcss@3 autoprefixer postcss
       ```

    2. Buat `tailwind.config.js` di root project — gunakan format CJS (karena package.json tidak punya "type":"module"):
       ```js
       /** @type {import('tailwindcss').Config} */
       module.exports = {
         content: [
           "./index.html",
           "./index.tsx",
           "./App.tsx",
           "./components/**/*.{tsx,ts}",
           "./contexts/**/*.{tsx,ts}",
         ],
         darkMode: 'class',
         theme: {
           extend: {
             colors: {
               primary: {
                 50: '#f0fdf4',
                 100: '#dcfce7',
                 500: '#22c55e',
                 600: '#16a34a',
                 700: '#15803d',
                 900: '#14532d',
               },
               dark: {
                 bg: '#0f172a',
                 card: '#1e293b',
                 border: '#334155',
               },
             },
             fontFamily: {
               mono: ['JetBrains Mono', 'monospace'],
             },
             animation: {
               'fade-in': 'fadeIn 0.2s ease-out',
             },
             keyframes: {
               fadeIn: {
                 '0%': { opacity: '0', transform: 'scale(0.95)' },
                 '100%': { opacity: '1', transform: 'scale(1)' },
               },
             },
           },
         },
         plugins: [],
       }
       ```

    3. Buat `postcss.config.js` di root project — format CJS:
       ```js
       module.exports = {
         plugins: {
           tailwindcss: {},
           autoprefixer: {},
         },
       }
       ```

    Avoid: Jangan gunakan format ESM (`export default`) — package.json tidak punya "type":"module".
    Avoid: Jangan install tailwindcss@4 — config format v4 berbeda (CSS-first), tidak kompatibel dengan config yang ada.
  </action>
  <verify>
    - `ls tailwind.config.js postcss.config.js` → keduanya ada
    - `cat package.json | grep tailwindcss` → menampilkan versi ^3.x.x di devDependencies
  </verify>
  <done>Packages terinstall, config files dibuat dengan custom theme dari index.html</done>
</task>

<task type="auto">
  <name>Task 2: Buat index.css + update index.tsx + bersihkan index.html</name>
  <files>index.css, index.tsx, index.html</files>
  <action>
    1. Buat `index.css` di root project:
       ```css
       @import url('https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700&family=JetBrains+Mono:wght@400;500&display=swap');

       @tailwind base;
       @tailwind components;
       @tailwind utilities;

       body {
         font-family: 'Inter', sans-serif;
       }

       ::-webkit-scrollbar { width: 8px; height: 8px; }
       ::-webkit-scrollbar-track { background: transparent; }
       ::-webkit-scrollbar-thumb { background: #cbd5e1; border-radius: 4px; }
       .dark ::-webkit-scrollbar-thumb { background: #475569; }
       ::-webkit-scrollbar-thumb:hover { background: #94a3b8; }
       ```

    2. Edit `index.tsx` — tambahkan import CSS sebagai baris pertama:
       ```typescript
       import './index.css';
       ```
       Letakkan sebelum `import React from 'react'`.

    3. Edit `index.html`:
       a. HAPUS blok ini:
          ```html
          <script src="https://cdn.tailwindcss.com"></script>
          ```
       b. HAPUS blok ini seluruhnya (dari `<script>` sampai `</script>`):
          ```html
          <script>
            tailwind.config = {
              darkMode: 'class',
              theme: { ... }
            }
          </script>
          ```
       c. HAPUS blok `<style>` yang berisi Google Fonts + scrollbar CSS:
          ```html
          <style>
            @import url('https://fonts.googleapis.com/...');
            body { font-family: 'Inter', sans-serif; }
            .font-mono { ... }
            /* Custom Scrollbar */
            ...
          </style>
          ```
          (Styles ini sudah dipindah ke index.css)

    Avoid: Jangan hapus script `importmap` — React dan lucide-react masih perlu ESM resolution.
    Avoid: Jangan hapus script jsPDF CDN — jsPDF tetap diload via CDN (bukan scope plan ini).
    Avoid: Jangan ubah `<link rel="manifest">` atau meta PWA tags.
  </action>
  <verify>

    - `grep -n "tailwind.config" index.html` → tidak ada hasil
    - `grep "index.css" index.tsx` → ada import
    - `cat index.css | grep "@tailwind"` → ada 3 baris @tailwind
    - `npm run build` berhasil, tidak ada error TypeScript
    - `grep -r "cdn.tailwindcss" dist/` → tidak ada hasil
  </verify>
  <done>AC-1 satisfied: build bersih tanpa CDN Tailwind</done>
