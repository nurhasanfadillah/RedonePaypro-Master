<objective>
## Goal
Fix tiga masalah browser console yang tersisa setelah Plan 03-01: Service Worker CORS error (sw.js masih mencache cdn.tailwindcss.com), deprecated meta tag warning, dan dead importmap entries (recharts + @supabase/supabase-js).

## Purpose
Setelah Plan 03-01 menghapus CDN Tailwind dari HTML, sw.js masih mencoba cache URL tersebut saat install → CORS block → `TypeError: Failed to fetch`. Plan ini membersihkan sisa-sisa tersebut sehingga browser console benar-benar bersih.

## Output
- `public/sw.js` — cdn.tailwindcss.com dihapus dari urlsToCache, Supabase check dihapus, CACHE_NAME dinaikkan ke v6
- `index.html` — meta tag `mobile-web-app-capable` ditambahkan, recharts + @supabase/supabase-js dihapus dari importmap
</objective>

```gherkin

```

<tasks>

<task type="auto">
  <name>Task 1: Fix public/sw.js — hapus CDN entry, hapus Supabase check, bump CACHE_NAME</name>
  <files>public/sw.js</files>
  <action>
    Edit `public/sw.js` dengan tiga perubahan:

    1. Naikkan CACHE_NAME dari `'redonepaypro-v5'` ke `'redonepaypro-v6'`
       — wajib agar browser menginstall SW baru dan menghapus cache lama yang masih berisi CDN entry

    2. Hapus `'https://cdn.tailwindcss.com',` dari array urlsToCache
       Array menjadi:
       ```javascript
       const urlsToCache = [
         '/',
         'https://cdnjs.cloudflare.com/ajax/libs/jspdf/2.5.1/jspdf.umd.min.js',
         'https://cdnjs.cloudflare.com/ajax/libs/jspdf-autotable/3.8.2/jspdf.plugin.autotable.min.js'
       ];
       ```

    3. Hapus blok Supabase check yang sudah stale di fetch handler:
       ```javascript
       // Supabase API — Network Only, jangan cache
       if (url.href.includes('supabase')) return;
       ```
       (Supabase tidak lagi digunakan sejak Phase 2)

    Avoid: Jangan ubah logika navigate handler atau Stale-While-Revalidate handler.
    Avoid: Jangan hapus urlsToCache untuk jsPDF — masih diload via CDN.
  </action>
  <verify>
    - `grep "cdn.tailwindcss" public/sw.js` → tidak ada hasil
    - `grep "supabase" public/sw.js` → tidak ada hasil
    - `grep "CACHE_NAME" public/sw.js` → menampilkan 'redonepaypro-v6'
  </verify>
  <done>AC-1 satisfied: SW tidak lagi mencoba cache cdn.tailwindcss.com</done>
</task>

<task type="auto">
  <name>Task 2: Fix index.html — tambah mobile-web-app-capable, hapus dead importmap entries</name>
  <files>index.html</files>
  <action>

    1. Tambahkan meta tag `mobile-web-app-capable` tepat SETELAH baris `apple-mobile-web-app-capable`:
       ```html
       <meta name="apple-mobile-web-app-capable" content="yes">
       <meta name="mobile-web-app-capable" content="yes">
       ```

    2. Hapus dua baris dari importmap:
       ```json
       "recharts": "https://esm.sh/recharts@2.12.7?external=react,react-dom",
       "@supabase/supabase-js": "https://esm.sh/@supabase/supabase-js@2.39.0",
       ```
       Importmap yang tersisa:
       ```json
       {
         "imports": {
           "react": "https://esm.sh/react@18.2.0",
           "react/jsx-runtime": "https://esm.sh/react@18.2.0/jsx-runtime",
           "react-dom": "https://esm.sh/react-dom@18.2.0",

           "react-dom/": "https://esm.sh/react-dom@^19.2.3/",
           "react/": "https://esm.sh/react@^19.2.3/"
         }
       }
       ```

    Avoid: Jangan hapus entry lucide-react, react, react-dom — masih digunakan.
    Avoid: Jangan ubah urutan atau format JSON importmap lainnya.
  </action>
