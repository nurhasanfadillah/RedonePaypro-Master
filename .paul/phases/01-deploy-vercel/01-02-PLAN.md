<tasks>
<task type="auto">
  <name>Hapus file PWA duplikat di root</name>
  <files>sw.js (delete), manifest.json (delete from root)</files>
  <action>
    Hapus dua file berikut dari root project:
    - `/sw.js` — versi lama (cache v4, `urlsToCache` menggunakan `'./index.html'` yang tidak canonical)
      Digantikan oleh `public/sw.js` (v5) yang lebih baru dan lebih bersih
    - `/manifest.json` — menggunakan `start_url: "./"` dan `scope: "./"` (relative, bermasalah)
      Digantikan oleh `public/manifest.json` yang menggunakan `start_url: "/"` (absolute, benar untuk Vercel)

    Kenapa aman dihapus:
    - Vite dev server: files di `public/` di-serve di root (`/sw.js` → `public/sw.js`)
    - Vite build: `public/sw.js` → `dist/sw.js`, `public/manifest.json` → `dist/manifest.json`
    - Root-level files TIDAK diproses Vite dan TIDAK masuk `dist/` secara default
    - `index.tsx:15` register `'./sw.js'` → resolve ke `/sw.js` → `dist/sw.js` dari `public/sw.js` ✓
    - `index.html` link `href="/manifest.json"` → resolve ke `dist/manifest.json` dari `public/manifest.json` ✓

    JANGAN ubah apapun di:
    - `public/sw.js` — ini versi canonical yang aktif
    - `public/manifest.json` — ini versi canonical yang aktif
    - `index.tsx` — registrasi path sudah benar
    - `index.html` — link manifest sudah benar
  </action>
  <verify>
    Setelah penghapusan, verifikasi:
    1. Root project tidak mengandung `sw.js` dan `manifest.json` (hanya ada di `public/`)
    2. `npm run build` berhasil tanpa error
    3. `dist/` mengandung `sw.js` (berasal dari `public/sw.js`) dan `manifest.json` (dari `public/manifest.json`)
  </verify>
  <done>AC-1 satisfied: Tidak ada file PWA duplikat, canonical source adalah public/</done>
</task>
