<task type="checkpoint:human-action" gate="blocking">
  <name>Task 2: Setup Vercel Project dan Deploy</name>
  <what-to-do>
    Buat Vercel project dan deploy app ini.

    **Langkah-langkah:**

    1. **Pastikan kode ada di GitHub:**
       - Cek `git remote -v` — apakah ada remote origin yang mengarah ke GitHub?
       - Jika belum: buat repo GitHub baru, push kode (`git push -u origin main`)

    2. **Import ke Vercel:**
       - Buka https://vercel.com/new
       - Pilih "Import Git Repository"
       - Pilih repo RedonePaypro-Master
       - Klik Import

    3. **Konfirmasi Build Settings** (Vercel biasanya auto-detect ini):
       - Framework Preset: **Vite**
       - Build Command: `npm run build`
       - Output Directory: `dist`
       - Install Command: `npm install`

    4. **Set Environment Variables** (di bagian "Environment Variables" sebelum deploy):
       ```
       VITE_SUPABASE_URL    = https://sartektzisafnmbiuhwd.supabase.co
       VITE_SUPABASE_ANON_KEY = [nilai dari Supabase dashboard atau supabaseClient.ts]
       ```
       > Tip: Buka services/supabaseClient.ts untuk melihat nilai hardcoded yang bisa digunakan

    5. **Klik Deploy** — tunggu build selesai (~1-2 menit)

    6. **Verifikasi:** Vercel akan memberi URL sementara (contoh: redone-paypro.vercel.app)
       - Buka URL tersebut
       - Pastikan halaman login muncul dan login berhasil
  </what-to-do>
  <resume-signal>Ketik "deployed" beserta URL Vercel sementara (contoh: redone-paypro.vercel.app) untuk lanjut ke Task 3, atau deskripsikan error yang muncul</resume-signal>
</task>

<task type="checkpoint:human-action" gate="blocking">
  <name>Task 3: Konfigurasi Custom Domain paypro.redone.my.id</name>
  <what-to-do>
    Sambungkan domain paypro.redone.my.id ke Vercel project.

    **Di Vercel Dashboard:**

    1. Buka project yang baru di-deploy
    2. Masuk ke **Settings → Domains**
    3. Ketik `paypro.redone.my.id` → klik **Add**
    4. Vercel akan menampilkan DNS record yang harus dikonfigurasi.
       Biasanya salah satu dari:
       ```
       CNAME  paypro  →  cname.vercel-dns.com
       ```
       atau A record ke IP Vercel.
       **Salin nilai yang ditampilkan Vercel** (jangan asumsikan — ambil dari dashboard).

    **Di DNS Provider domain redone.my.id:**

    5. Login ke DNS provider (Cloudflare? IDCloudHost? Niagahoster?) tempat domain `redone.my.id` dikelola
    6. Buka DNS Management / DNS Records
    7. Tambahkan record sesuai yang ditampilkan Vercel di langkah 4:
       ```
       Type : CNAME
       Name : paypro          (hanya subdomain-nya, bukan full domain)
       Value: cname.vercel-dns.com   (sesuai yang ditampilkan Vercel)
       TTL  : Auto atau 3600
       ```
    8. Simpan / Save

    **Tunggu propagasi DNS:**

    9. Kembali ke Vercel Settings → Domains
    10. Tunggu status berubah dari "Invalid Configuration" → **Valid** (5-60 menit)
    11. Vercel akan otomatis provision SSL certificate via Let's Encrypt
    12. Setelah valid, buka https://paypro.redone.my.id — harus muncul halaman login dengan HTTPS
  </what-to-do>
  <resume-signal>Ketik "live" setelah https://paypro.redone.my.id dapat diakses dengan HTTPS, atau deskripsikan status Vercel dan DNS provider jika ada kendala</resume-signal>
</task>
