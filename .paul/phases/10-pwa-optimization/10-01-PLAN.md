<objective>
## Goal
Audit dan optimalisasi PWA: perbaiki manifest.json (icons + metadata lengkap), perkuat Service Worker (update notification + cache resilience), dan tambahkan indikator offline di UI.

## Purpose
PWA saat ini minimal — manifest hanya 2 icon size, SW tidak memberitahu user saat update tersedia, dan tidak ada tanda saat app offline. Optimalisasi ini memastikan PWA memenuhi best practice untuk installability, update flow, dan offline resilience.

## Output
- `public/manifest.json`: ikon multi-size + purpose maskable + categories + screenshots + lang
- `public/sw.js`: SW update notification, cache version bump v7→v8, CDN fallback hardening
- `index.html`: meta description + viewport-fit=cover
- `index.tsx`: update detector + toast "versi baru tersedia"
</objective>

<task type="auto">
  <name>Task 2: Hardening sw.js — update notification + CDN resilience</name>
  <files>public/sw.js</files>
  <action>
    Update public/sw.js dengan 3 perubahan:

    **A. Bump CACHE_NAME:** `v7` → `v8`

    **B. Tambahkan message handler untuk SKIP_WAITING** — setelah SW line `self.clients.claim();`, tambahkan:
    ```js
    // Message handler untuk skip waiting (digunakan oleh update prompt)
    self.addEventListener('message', (event) => {
      if (event.data === 'SKIP_WAITING') {
        self.skipWaiting();
      }
    });
    ```

    **C. Gunakan `event.waitUntil` + `clients.claim()` di `install`** (ganti `skipWaiting()` di `install` dengan pattern yang lebih kontrol). Ubah baris `self.skipWaiting();` di install menjadi:
    ```js
    // Tidak auto skipWaiting — biarkan update prompt dari index.tsx yang trigger
    ```
    (Hapus `self.skipWaiting()` dari install handler, karena akan di-trigger manual via message)

    Final file structure (ganti file secara penuh):
    ```js
    const CACHE_NAME = 'redonepaypro-v8';
    const urlsToCache = [
      '/',
      'https://cdnjs.cloudflare.com/ajax/libs/jspdf/2.5.1/jspdf.umd.min.js',
      'https://cdnjs.cloudflare.com/ajax/libs/jspdf-autotable/3.8.2/jspdf.plugin.autotable.min.js'
    ];

    // Install SW
    self.addEventListener('install', (event) => {
      event.waitUntil(
        caches.open(CACHE_NAME)
          .then((cache) => cache.addAll(urlsToCache))
          .catch((err) => console.warn('SW install partial:', err))
      );
    });

    // Activate SW & Clean old caches
    self.addEventListener('activate', (event) => {
      event.waitUntil(
        caches.keys().then((cacheNames) =>
          Promise.all(
            cacheNames
              .filter((name) => name !== CACHE_NAME)
              .map((name) => caches.delete(name))
          )
        )
      );
      self.clients.claim();
    });

    // Message handler untuk skip waiting
    self.addEventListener('message', (event) => {
      if (event.data === 'SKIP_WAITING') {
        self.skipWaiting();
      }
    });

    // Fetch Handler
    self.addEventListener('fetch', (event) => {
      const url = new URL(event.request.url);

      // Skip non-http
      if (!url.protocol.startsWith('http')) return;

      // Navigation — Network First, fallback cache
      if (event.request.mode === 'navigate') {
        event.respondWith(
          fetch(event.request)
            .then((res) => (res.ok ? res : caches.match('/')))
            .catch(() => caches.match('/'))
        );
        return;
      }

      // Skip API requests
      if (url.pathname.startsWith('/api/')) {
        event.respondWith(fetch(event.request));
        return;
      }

      // Static Assets — Stale-While-Revalidate
      event.respondWith(
        caches.match(event.request).then((cached) => {
          const network = fetch(event.request).then((res) => {
            if (res && res.status === 200 && (res.type === 'basic' || res.type === 'cors')) {
              const resClone = res.clone();
              caches.open(CACHE_NAME).then((cache) => cache.put(event.request, resClone));
            }
            return res;
          }).catch(() => {});

          return cached || network;
        })
      );
    });
    ```
  </action>

    **B. Update index.tsx** — ganti blok SW registration (lines 13-24) dengan kode yang lebih robust:

    ```tsx
    // Registrasi Service Worker untuk PWA
    if ('serviceWorker' in navigator) {
      window.addEventListener('load', () => {
        let refreshing = false;

        navigator.serviceWorker.register('./sw.js')
          .then(registration => {
            console.log('PWA SW registered:', registration.scope);

            // Deteksi SW update
            registration.addEventListener('updatefound', () => {
              const newWorker = registration.installing;
              if (!newWorker) return;

              newWorker.addEventListener('statechange', () => {
                if (newWorker.state === 'installed' && navigator.serviceWorker.controller && !refreshing) {
                  const update = confirm('Pembaruan tersedia — muat ulang sekarang?');
                  if (update) {
                    refreshing = true;
                    newWorker.postMessage('SKIP_WAITING');
                    window.location.reload();
                  }
                }
              });
            });
          })
          .catch(error => {
            console.error('PWA SW registration failed:', error);
          });

        // Offline/online indicator
        const showOfflineBanner = () => {
          const existing = document.getElementById('offline-banner');
          if (existing) return;
          const banner = document.createElement('div');
          banner.id = 'offline-banner';
          banner.className = 'fixed bottom-0 left-0 right-0 bg-amber-500 text-amber-900 text-center text-sm font-bold py-2 z-50';
          banner.textContent = 'Anda sedang offline — beberapa fitur tidak tersedia';
          document.body.appendChild(banner);
        };

        const hideOfflineBanner = () => {
          const banner = document.getElementById('offline-banner');
          if (banner) banner.remove();
        };

        window.addEventListener('offline', showOfflineBanner);
        window.addEventListener('online', hideOfflineBanner);

        if (!navigator.onLine) showOfflineBanner();
      });
    }
    ```

    Avoid: Gunakan `confirm()` bukan custom modal agar tanpa dependency ke React — banner muncul bahkan sebelum React mount. Alternatif: jika user mau toast package, bisa pakai react-hot-toast yang sudah ada, tapi `confirm()` lebih simple dan reliable saat React belum selesai render.
  </action>
