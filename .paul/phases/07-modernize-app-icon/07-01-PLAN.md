<objective>
## Goal
Ganti ikon aplikasi (PWA, favicon, splash screen, sidebar) dengan logo SVG modern self-hosted — hapus ketergantungan Flaticon CDN.

## Purpose
Ikon branded yang konsisten di semua touchpoint: tab browser, Android home screen, iOS home screen, splash screen, dan sidebar app. Zero CDN dependency.

## Output
- `public/icon.svg` — master SVG logo (monogram "RP" modern)
- `public/icon-192.png` — PWA icon 192x192
- `public/icon-512.png` — PWA icon 512x512
- `public/apple-icon-180.png` — Apple touch icon 180x180
- `public/manifest.json` — updated icon paths
- `index.html` — updated favicon + apple-touch-icon
- `App.tsx` — sidebar brand pakai SVG baru
</objective>
